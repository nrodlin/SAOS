    Misregistration¶

    Theory and implementation¶

    MisRegistration models the misalignment of a deformable mirror (DM) with respect to the pupil as a geometric transformation of the DM OPD map, defined on the telescope pupil grid (pixel \(\delta = D/N\)). The parameters are a shift \((s_x, s_y)\) in metres (\(x\) = columns, \(y\) = rows), a rotation \(\beta\) in degrees about the optical axis, and a radial scaling \(m\) (magnification, \(m>1\) enlarges the pattern). Optional constant rates \((v_x, v_y, w_z)\) make the parameters drift linearly: after an elapsed time \(\Delta t\), update_params does \(s \mathrel{+}= v\,\Delta t\), \(\beta \mathrel{+}= w_z\Delta t\) (the scaling is constant).

    apply_misreg transforms the OPD map \(O(\mathbf{p})\) in this order:

    1. Scaling about the array centre, \(O_1(\mathbf{p}) = O\big(\mathbf{c} + (\mathbf{p}-\mathbf{c})/m\big)\) (cv2.warpAffine, bilinear), applied only if \(m\ne1\). The centre used is \((N/2, N/2)\).
    2. Rotation by \(\beta\) about the array centre (scipy.ndimage.rotate, cubic spline, reshape=False), the sense being that of scipy.ndimage.rotate on the array axes \((\text{row}, \text{col})\); applied only if \(\beta\ne0\).
    3. Shift by \((s_x/\delta,\ s_y/\delta)\) pixels (cv2.warpAffine, bilinear): positive \(s_x\) moves the pattern towards \(+\)column and positive \(s_y\) towards \(+\)row. Sub-pixel shifts are allowed (unlike the atmosphere).

    The borders are filled with the nearest value (BORDER_REPLICATE / mode='nearest') instead of zeros, because the DM OPD does not vanish at the edge of the array: a zero border would distort the pupil edge for any non-null misregistration. The transformation is applied to the whole DM OPD map, i.e. the misregistration of the DM is modelled as an image transform (this includes the influence-function shape); the DM class also has a separate, exact treatment that moves the actuators, see Deformable Mirror. The transformation is a rigid-body plus isotropic scaling; no anisotropic magnification, pupil distortion or time-varying scaling is modelled. Bilinear interpolation slightly smooths the map, especially for sub-pixel shifts and for the magnification.

    def update_params(self, elapsedTime):

    self.shiftX   += self.vx * elapsedTime
    self.shiftY   += self.vy * elapsedTime
    self.rotation += self.wz * elapsedTime

    def apply_misreg(self, input_buffer):

    # The DM OPD is not null at the border of the array (the pupil fills it), so the borders are extended with the
    # nearest value: a constant (zero) border distorts the pupil edge for any non-null misregistration, even 1e-9 deg
    temp_buffer = np.copy(input_buffer)
    if self.radialScaling != 1:
        # Apply magnification
        scalingMatrix = cv2.getRotationMatrix2D((input_buffer.shape[1]/2,input_buffer.shape[0]/2), 0, self.radialScaling)
        temp_buffer = cv2.warpAffine(input_buffer, scalingMatrix, (input_buffer.shape[1], input_buffer.shape[0]),
                                     flags=cv2.INTER_LINEAR,
                                     borderMode=cv2.BORDER_REPLICATE)

    if self.rotation != 0:
        # Apply rotation: cubic spline (order 3), sub-nm round-trip error on the DM OPD
        temp_buffer = sp.ndimage.rotate(temp_buffer, self.rotation, reshape=False, order=3, mode='nearest')

    # Apply shift
    if self.shiftX != 0 or self.shiftY != 0:
        translationMatrix = np.float32([[1, 0, self.shiftX/self.spatialSampling], [0, 1, self.shiftY/self.spatialSampling]])
        temp_buffer = cv2.warpAffine(temp_buffer, translationMatrix, (temp_buffer.shape[1], temp_buffer.shape[0]),
                                    flags=cv2.INTER_LINEAR, 
                                    borderMode=cv2.BORDER_REPLICATE)

    return temp_buffer
