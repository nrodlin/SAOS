    Source¶

    Theory and implementation¶

    Source models a natural point source at infinity (NGS). Any laser guide star parameter (finite altitude, sodium profile, launch coordinates, spot FWHM) raises NotImplementedError.

    Position and frames¶

    coordinates = [rho, theta] is the direction of the source with respect to the telescope axis, \(\rho\) in arcsec and \(\theta\) in degrees, so that on the sky \(x = \rho\cos\theta\) (columns of the phase screens) and \(y = \rho\sin\theta\) (rows). The same frame is used by the atmosphere footprints, the DM projection and the wind directions (see Atmosphere). The optional chromatic_shift is an array of shape \((N_L, 2)\) with an extra \((dx, dy)\) in arcsec per atmospheric layer, added to the source direction when the footprint on each layer is computed (a model of atmospheric dispersion; it is common to all sources of that wavelength).

    Photometry¶

    Each band of PHOTOMETRY_BANDS is a tuple \([\lambda_c,\ \Delta\lambda,\ Z]\) (central wavelength and bandwidth in m, zero-point flux). The photon flux at the telescope is

    \[ \Phi = \frac{Z}{368}\;10^{-0.4\,m} \quad [\mathrm{photons\,m^{-2}\,s^{-1}}], \]

    with \(m\) the apparent magnitude. The zero points of the table are divided by an empirical constant (368, inherited from the OOMAO photometry tables), which gives \(\Phi\approx 9\times10^{9}\) photons m\(^{-2}\) s\(^{-1}\) for \(m_V=0\). The bandwidth is stored but not used to compute the flux (it is folded in the zero point). The number of photons collected by a sensor in an integration time \(T\) is computed by the sensor as \(\Phi\,A_{eff}\,T\,\eta\) with \(A_{eff}\) from the Telescope and \(\eta\) the light ratio of the sensor. The table is a fixed set of broadband (U to M) and narrow bands (e.g. Na, EOS, IR1310) and is approximate: no colour, spectral type or atmospheric extinction is modelled. The source is monochromatic at \(\lambda_c\) (phase scaled as \(500\,\mathrm{nm}/\lambda_c\) in the atmosphere, no polychromatic propagation). Source.print_available_bands() lists the table.

        def __init__(self,
                 optBand:str,
                 magnitude:float,
                 coordinates:list = [0,0],
                 altitude:float = np.inf,
                 laser_coordinates:list = None,
                 Na_profile:np.ndarray = None,
                 FWHM_spot_up:float = None,
                 chromatic_shift:list = None,
                 logger = None):
        """
        Initialize a Source object.

        Parameters
        ----------
        optBand : str
            Optical band identifier. Available bands include:
            - 'U', 'B', 'V', 'V0', 'V1', 'R', 'R2'-'R4'
            - 'I', 'I1'-'I10'
            - 'J', 'J2', 'H'
            - 'Kp', 'Ks', 'K', 'K0', 'K1'
            - 'L', 'M', 'Na', 'EOS', 'IR1310'
            Call Source.print_available_bands() to see their central wavelengths, 
            bandwidths, and zero-point fluxes.
        magnitude : float
            Apparent magnitude of the star.
        coordinates : list, optional
            Sky coordinates [zenith, azimuth] in [arcsec, degrees], by default [0, 0].
        altitude, laser_coordinates, Na_profile, FWHM_spot_up : optional
            Laser guide star parameters (finite altitude, launch telescope coordinates, sodium profile, uplink spot FWHM).
            LGS are not implemented in SAOS: giving any of them raises NotImplementedError. The source is always natural
            (altitude = infinity).
        chromatic_shift : array-like, optional
            Chromatic dispersion: one on-sky shift vector (dx, dy) [arcsec] per atmospheric layer, shape (nLayer, 2), x = +column
            and y = +row; it is added to the direction of the source (common to all the sources of this wavelength).
        logger : logging.Logger, optional
            Logger instance for logging.
        """
# %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% INITIALIZATION %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%% 
        # Setup the logger to handle the queue of info, warning and errors msgs in the simulator
        self.logger = logger if logger is not None else get_logger()

        self.is_initialized = False
        tmp             = self.photometry(optBand)              # get the photometry properties
        self.optBand    = optBand                               # optical band
        self.wavelength = tmp[0]                                # wavelength in m
        self.bandwidth  = tmp[1]                                # optical bandwidth
        self.zeroPoint  = tmp[2]/368                            # zero point
        self.magnitude  = magnitude                             # magnitude
        self.phase      = []                                    # phase of the source 
        self.phase_no_pupil      = []                           # phase of the source (no pupil)
        self.fluxMap    = []                                    # 2D flux map of the source
        self.flux       = self.zeroPoint*10**(-0.4*magnitude)   # flux [photons/m²/s]
        # Laser guide stars are not implemented: refuse any LGS parameter instead of simulating the source as a natural one
        if np.isfinite(altitude) or laser_coordinates is not None or Na_profile is not None or FWHM_spot_up is not None:
            self.logger.error('Source::__init__ - Laser guide stars (finite altitude, Na_profile, FWHM_spot_up, laser_coordinates) '
                              'are not implemented in SAOS.')
            raise NotImplementedError('Laser guide stars (finite altitude, Na_profile, FWHM_spot_up, laser_coordinates) are not '
                                      'implemented in SAOS: only natural sources (altitude = infinity) are supported.')
        self.tag        = 'source'                              # tag of the object
        self.altitude   = np.inf                                # natural source at infinity
        self.coordinates = coordinates                          # polar coordinates [r,theta] 
        self.chromatic_shift = chromatic_shift                             # shift in arcsec to be applied to the atmospheric phase screens (one value for each layer) to simulate a chromatic effect
        self.type     = 'NGS'

        self.is_initialized = True

    @classmethod
def print_available_bands(cls):
    """
    Prints the available optical bands and their properties.
    """
    print(f"{'Band':<8} | {'Wavelength (m)':<15} | {'Bandwidth (m)':<15} | {'Zero Point Flux':<15}")
    print("-" * 65)
    for band, props in cls.PHOTOMETRY_BANDS.items():
        print(f"{band:<8} | {props[0]:<15.3e} | {props[1]:<15.3e} | {props[2]:<15.3e}")

    def photometry(self,arg):
    """
    Returns photometric properties of the selected band.

    Parameters
    ----------
    arg : str
        Name of the photometric band (e.g., 'V', 'H', 'Na').

    Returns
    -------
    list or int
        List of [wavelength, bandwidth, zero-point flux] or -1 if invalid.
    """
    self.logger.debug('Source::photometry')

    if isinstance(arg,str):
        if arg in self.PHOTOMETRY_BANDS:
            return self.PHOTOMETRY_BANDS[arg]
        else:
            self.logger.error(f'Source::photometry - Wrong name for the photometry object. Available bands: {self.get_available_bands()}')
            raise ValueError(f'Wrong name for the photometry object. Available bands: {self.get_available_bands()}')
    else:
        self.logger.error('Source::photometry - The photometry object takes a string as an input.')
        raise ValueError('The photometry object takes a string as an input.')

    def print_properties(self):
    """
    Print the main properties of the source.

    Returns
    -------
    None
    """
    self.logger.info('Source::print_properties')
    self.logger.info('{: ^8s}'.format('Source') +'{: ^10s}'.format('Wavelength')+ '{: ^8s}'.format('Zenith')+ '{: ^10s}'.format('Azimuth')+ '{: ^10s}'.format('Altitude')+ '{: ^10s}'.format('Magnitude') + '{: ^10s}'.format('Flux'))
    self.logger.info('{: ^8s}'.format('') +'{: ^10s}'.format('[m]')+ '{: ^8s}'.format('[arcsec]')+ '{: ^10s}'.format('[deg]')+ '{: ^10s}'.format('[m]')+ '{: ^10s}'.format('') + '{: ^10s}'.format('[phot/m2/s]') )

    self.logger.info('-------------------------------------------------------------------')        
    self.logger.info('{: ^8s}'.format(self.type) +'{: ^10s}'.format(str(self.wavelength))+ '{: ^8s}'.format(str(self.coordinates[0]))+ '{: ^10s}'.format(str(self.coordinates[1]))+'{: ^10s}'.format(str(np.round(self.altitude,2)))+ '{: ^10s}'.format(str(self.magnitude))+'{: ^10s}'.format(str(np.round(self.flux,1))) )
